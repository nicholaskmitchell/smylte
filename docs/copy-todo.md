# Copy to write

Field notes (Nov 2026) keeps every existing label. Where the redesign needed text
that did not exist, the app shows a visible `[placeholder: …]` instead of copy
written for you. Each one is listed here with its screen, its purpose and the
i18n key that holds it (both `en.ts` and `de.ts` carry the same placeholder).

Replace a placeholder by editing its key in `frontend/src/i18n/en.ts` and
`frontend/src/i18n/de.ts`, then delete its row here.

## Notes

Lines Field notes keeps, although a strict reading of "name things, do not explain them" would remove them. Each is a warning, a privacy note or a legal notice, and sits beside the setting it is about. Strike any that you would rather lose.

| Key | English |
|---|---|
| `conn.hint` | Disconnecting revokes access immediately. |
| `shares.rotateHint` | Keeps these settings. The old link stops working at once. |
| `disp.rotateHint` | A new URL keeps this display’s settings. Point the screen at it afterwards. |
| `disp.refreshEinkHint` | E-ink panels can be damaged by refreshing more often than every 3 minutes. |
| `mail.imap.rebind` | Changing the host, port, encryption, certificate or username clears the saved password. |
| `mail.enabled.hint` | The first check reads the last {days} days. Set up the sender lists first, because skipped mail isn’t read again. |
| `mail.secret.hint` | Not shown again after saving. |
| `mail.cert.insecureWarning` | Certificate checks are off, so anyone on this connection can read your mail and Bridge password. Only allowed for localhost. Pin the certificate if you can. |
| `notif.token.hint` | Create a bot with @BotFather and paste its token. It isn’t shown again after saving. |
| `settings.autoCloseParents.hint` | Subtasks marked won’t-do count as done. Parked ones don’t. The completion syncs to your other apps. |
| `disp.urlHint` | Anyone with this URL can see what the screen shows. Get a new URL if it leaks. |
| `shares.urlHint` | Anyone with this link sees what you pick here, until you turn it off or make a new link. |
| `about.hint` | Source for the version running here. If you run a modified copy that others use over a network, the AGPL requires you to offer them its source. |
