# Contributing

The canonical home of this project is on GitLab:
<https://gitlab.com/nicholaskmitchell/smylte>

You are welcome to contribute from either platform. Use whichever you prefer.

## From GitLab (preferred)

Fork the project or push a branch, then open a merge request.

## From GitHub

Open a pull request at <https://github.com/nicholaskmitchell/smylte> as usual.
A workflow copies it to a merge request on GitLab, where it is reviewed and
merged. When the change is merged on GitLab, your pull request is marked as
merged automatically.

A few things to know:

- The GitHub repository is a mirror of GitLab. Changes pushed directly to its
  default branch will be overwritten by the next mirror update.
- Review happens on GitLab, so comments and questions may appear on the merge
  request rather than on your pull request.
- Automated checks do not run on outside contributions until a maintainer has
  looked at the change and started them.
- Issues and discussions on GitHub are not synced, so GitLab is the better
  place to report a problem.
